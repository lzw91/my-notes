# 8.1数组
## 8.11数组的基本概念
### 定义
数组是按照顺序存储的一系列**类型相同**的值。单独的的项称为==数组元素==
### 声明
声明了数组的**数组名**，**元素个数**，**元素类型**。
例如`int arr[20]`方括号表明arr是一个数组，方括号的数组表明了数组种的元素个数，数据类型int表明数组存储的元素的数据类型是int
### 数组下标
可以通过数组下标数访问数组中的各元素。下标编号数从**0到n-1**。例如
`arr[0]`表示的是数组arr的第一个元素。`arr[19]`为最后一个元素
## 8.12数组的输入
>两大种方法可以给数组存入数据

### 数组初始化
#### 列表初始化法
1. **完全**初始化：在创建数组的时候把**花括号**括起来的**逗号分隔**的值列表赋值给数组，且列表元素数量等于数组元素数量
例：`int arr[5] = {1,2,3,4,5}`
2. **部分**初始化：列表元素少于数组元素，会**把剩余元素初始化为0**
例：`int arr[5]={1,2}`等价于`int arr[5]={1,2,0,0,0}`
可利用这个让列表中只有
#### 指定初始化器（C99）
==结构形式==：在花括号列表中添加`[n]=m`的结构。该特性可以初始化指定的数组元素，**把第n-1个元素初始化为m**。未被初始化的元素全部初始化为0
例：`int arr[5]={[4]=1}`，把int数组arr最后一个元素初始化为1，其他全为0
==初始化器特性==
1. 如果指定初始化器后面有更多的值
    例如`{[4]=5,2,3}`则把第五个和第六个分别初始化为2，3
2. 如果再次初始化指定的元素，后面初始化将取代之前的初始化
	例如`{1,2,[4]=5},2,3,[0]=0`最后的初始化器将取代最开始列表中的值，最终第一个元素为0，而不是1
>[! Note] 初始化省略方括号中的数字
>按照上述列表初始化和指定初始化器的方法，元素有多少个，就创建多大的数组
### 数组赋值
利用循环语句进行赋值，数组中的元素可以看作一个个独立的变量，故可以用`scanf`函数进行输入
例：`int arr[5];`
```C
int i;
for(i=0;i<5;i++){
	scanf("%d",&arr[i]);
}
```
