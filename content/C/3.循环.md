# 3.1`while`语句
## 3.11`while`基本语法
`while`语句的通用形式为
```
while(expression)
	statement
```
1. statement可以是以==分号结尾的简单语句==，也可以是用==花括号括起来的复合语句==
2. expression部分可以使用关系表达式。如果expression为==真(非0)==，则==执行statement部分==，然后再次判断expression。expression==为假(0)==的时候==循环结束==。因此while语句的测试表达式最终一定要为假
>[!note] 空语句
>注意不要写成`while(语句);`的形式，这个单独的分号会被视作一条空语句,有可能会陷入无限循环，也可以利用空语句跳过一些输入例如`while(scanf("%d",&num)==1);`，这个可以跳过输入到达第一个非空白字符和数字的位置
